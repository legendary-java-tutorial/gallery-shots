# Як додати свою картку

1. Відкрийте Issue «Картка <логін>» за шаблоном.
2. Зробіть форк, гілку `card-<логін>` від свіжої `main`.
3. Файл `cards/<логін>.json`: поля `name`, `profile`, `project` — адреси повністю, з `https://`.
4. Один коміт із повідомленням `feat: картка <логін>`; виправлення — `fix: …`.
5. Pull Request у `main` галереї, в описі — `Closes #<номер Issue>`.

Редагуйте лише свій файл: чужі картки та спільні файли — окремим Issue.

## Допомога ШІ

Агента можна залучати. В описі PR — що робив ШІ і що ви перевірили самі; у коміті — рядок `Assisted-by: <агент> (<що робив>)`. На рев'ю відповідайте самі.
